📦 CRUD Application

A simple and clean full-stack CRUD (Create, Read, Update, Delete) application built using Angular, ASP.NET Core Web API, and SQL Server.
The app demonstrates basic full-stack development, API integration, and database operations.

🚀 Features

Add new records

View all records

Edit/update existing records

Delete records

Responsive UI with Angular

Backend built using ASP.NET Core Web API

SQL Server database with ADO.NET queries

🛠️ Tech Stack

Frontend: Angular, TypeScript
Backend: ASP.NET Core Web API
Database: SQL Server (ADO.NET)
